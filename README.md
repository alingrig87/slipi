# Slipi - Aplicație de somn pentru copii

Aplicație React Native pentru gestionarea somnului copiilor.

## Tehnologii

- React Native
- Expo
- React 19.1.0

## Instalare

```bash
npm install
```

## Rulare

```bash
# Start development server
npm start

# Run on Android
npm run android

# Run on iOS (necesită macOS)
npm run ios

# Run on Web
npm run web
```

## Structură proiect

```
slipi/
├── App.js          # Componenta principală
├── app.json        # Configurație Expo
├── assets/         # Imagini și resurse
└── package.json    # Dependențe
```

## Dezvoltare

Aplicația este în faza inițială de dezvoltare. Structura de bază este pregătită pentru adăugarea funcționalităților de gestionare a somnului.
